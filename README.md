# O Maior Amor

Jogo de cerca de 2 minutos em pixel art, feito com o mesmo motor de "Quem é Ele?", sobre João 15:13:
"Ninguém tem maior amor do que aquele que dá a sua vida pelos seus amigos."

Endereço: `https://sah123campos.github.io/quem-e-ele/`

- **Parte 1, A pergunta:** no pátio, a equipe pergunta qual é a maior prova de amor. O jogador ouve quatro amigos e volta para a Débora.
- **Parte 2, Uma noite em Jerusalém:** o último jantar de Jesus com os discípulos (João 13–15). Jesus diz a frase, e depois vem o que aconteceu: a cruz e o túmulo vazio.
- **Final:** "Ele te chama de amigo." e o convite para o Culto Adoles.

Textos: `src/dialogos.js`. Convite: `src/config.js`. Tela final: `src/final.js`.
Teste rápido de uma fase: `?debug&sala=ceia`.
